# Analysis: Document Grid Layout & Sizing Tests

## 1. Executive Summary
Located existing document grid and layout unit tests under the Swift Package `Packages/Feature.InvoiceTemplateEditor`. The tests verify layout math, CoreText-based height estimation, border geometry, and parity between the interactive canvas and PDF export.

## 2. Located Test Files
All files are located in `Packages/Feature.InvoiceTemplateEditor/Tests/Feature_InvoiceTemplateEditorTests/`:

1. **`DocumentGridHeightReliabilityTests.swift`**
   - **Focus**: CoreText-based mathematical height calculation accuracy. Tests text wrapping, font-aware line calculations, auto-height versus fixed-height sizing configurations, and height reconciliation policies (analytic vs. inflated/partial measurement authority).
2. **`DocumentGridHeightRegressionTests.swift`**
   - **Focus**: Prevents height collapse or over-expansion. Verifies minimum/maximum row heights and container bounds clamping.
3. **`DocumentGridHeightWiringTests.swift`**
   - **Focus**: Integration parity. Verifies that calculated canvas height matches output PDF export height under various conditions.
4. **`DocumentGridExportLayoutTests.swift`**
   - **Focus**: Layout engine width allocation, spacing constraints, and borders in export-oriented grid layouts.
5. **`DocumentGridDataHiddenFieldsTests.swift`**
   - **Focus**: Data hiding rules in inspector components and grid tables.

## 3. Test Structure & Design
- **Base framework**: XCTest.
- **Target**: `Feature_InvoiceTemplateEditorTests`.
- **Methodology**: Isolates layout calculation structures and runs mathematical checks on height/width allocations without requiring UI hosting or device simulators.

## 4. Build & Test Execution
- **Swift Package Manager**:
  - Command: `swift test --package-path Packages/Feature.InvoiceTemplateEditor`
  - Output: Compiles and runs 160 unit tests successfully in the package target.
- **Xcode / xcodebuild**:
  - Main app target (`InvoicingApplication`) contains `AppSessionTests` but does not include these package tests in its test actions.
  - Xcode scheme `Feature_InvoiceTemplateEditor` is autogenerated but not configured for test action via CLI (`xcodebuild test` fails).
  - **Verdict**: Use `swift test` in the package root to execute tests.
